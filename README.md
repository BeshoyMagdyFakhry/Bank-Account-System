# Bank Account System

A console-based Bank Account Management System developed in C++ using Object-Oriented Programming principles.

## Overview

This project was created to apply core OOP concepts in a practical way. It simulates a banking system where users can create accounts, perform deposits and withdrawals, transfer money between accounts, view balances, and search account information.

## Features

- Create and manage Savings accounts
- Create and manage Checking accounts
- Deposit money
- Withdraw money
- Transfer funds between accounts
- Search account by account number or name
- View account details and balances
- Calculate savings interest
- Check checking account limits
- Manage accounts using a dedicated Bank class

## Object-Oriented Concepts Used

- Classes and objects
- Encapsulation
- Inheritance
- Constructors
- Function overloading
- References
- Arrays and loops
- Input validation
- Conditional logic

## Project Description

This system allows the user to:
- Open new bank accounts
- View all accounts in the bank
- Search for an account using its number or its name
- Transfer money between two accounts
- Access account details and perform transactions
- Calculate yearly or monthly interest for savings accounts
- Check limits for checking accounts

## Example Functionalities

- Savings Account:
  - Deposit money
  - Withdraw money
  - View balance
  - Calculate interest

- Checking Account:
  - Deposit money
  - Withdraw money
  - Check transfer and withdrawal limits
  - View balance

1. Open a C++ compiler or IDE
2. Create a new C++ project
3. Copy the source code into the main file
4. Compile and run the program

```bash
g++ main.cpp -o bank

```
